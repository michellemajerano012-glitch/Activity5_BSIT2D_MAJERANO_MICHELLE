Stacks and Queues: Array vs. Linked List

Project Description

This project implements stacks and queues using arrays and singly linked lists. It demonstrates the differences between LIFO and FIFO data structures, including their basic operations and error handling.

Files

- "array_stack.py" — Implements a fixed-capacity array stack.
- "linked_stack.py" — Implements a stack using a singly linked list.
- "array_queue.py" — Implements a circular array queue.
- "linked_queue.py" — Implements a queue using a singly linked list with head and tail references.
- "main.py" — Provides a menu for selecting a data structure and performing operations.
- "analysis.md" — Explains the linked-list stack and circular queue designs.
- "sample-runs.md" — Documents example operations and error handling.

Features

- Push and pop operations for stacks.
- Enqueue and dequeue operations for queues.
- Peek operations.
- Empty and full checks.
- Underflow and overflow error handling.
- Menu-driven program.
